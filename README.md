# Dishio

**Cook what you have or what you crave.**

Dishio is an installable web app (PWA) that turns the ingredients you have, or the dish you are craving, into five simple recipes generated by Google Gemini. Recipes adapt to your country, your budget and the equipment you have on hand.

## Features

- **Five recipes per request.** Each one has ingredients, steps, cooking time and an estimated cost.
- **Country-aware.** Ingredients and prices follow the selected country and its currency.
- **Cooking situations.** Choose *No limits*, *Only 15 minutes*, *Rice cooker only* or *No stove*.
- **Budget mode.** Set a maximum cost per dish. With a budget, the ingredients you enter are treated as things to buy and their cost is included.
- **Ingredient swaps.** Suggests up to three substitutes for any ingredient, with items from your fridge listed first.
- **My fridge.** Track ingredients and how long they keep. Items are sorted by freshness, and *Cook with these* builds a request from the items that expire soonest.
- **Saved recipes.** Save favourites and open them offline.
- **Read aloud.** Reads the cooking steps aloud, with pause, resume and stop.
- **Installable.** Runs as a standalone app on desktop and mobile.

Fridge contents, saved recipes and preferences are stored locally in the browser. There are no user accounts.

## Getting started

### Prerequisites

- Python 3.10 or newer
- A Gemini API key from [Google AI Studio](https://aistudio.google.com/app/apikey)

### Windows

Double-click `start.bat`. On the first run it:

1. creates a virtual environment in `.venv` and installs the dependencies;
2. creates `.env` from `.env.example` and opens it in Notepad.

Add your key after `GEMINI_API_KEY=`, save the file and close Notepad. The server starts at <http://localhost:5000>.

### Manual setup (any OS)

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # then set GEMINI_API_KEY
python app.py
```

Open <http://localhost:5000>. To install the app, use the install button in the browser's address bar (Chrome or Edge).

## Configuration

All settings are read from `.env` locally, or from environment variables when hosted.

| Variable | Default | Description |
|---|---|---|
| `GEMINI_API_KEY` | none (required) | Gemini API key |
| `GEMINI_MODEL` | `gemini-3.5-flash-lite` | Primary model |
| `GEMINI_FALLBACK_MODELS` | `gemini-3.1-flash-lite,gemini-2.5-flash` | Models tried in order if the primary model is overloaded, rate limited or unavailable. Use `none` to disable fallback. |
| `GEMINI_TIMEOUT_SECONDS` | `60` | Request timeout |
| `RATE_LIMIT_PER_MINUTE` / `RATE_LIMIT_PER_DAY` | `5` / `50` | Recipe requests per client |
| `SHELF_LIFE_PER_MINUTE` / `SHELF_LIFE_PER_DAY` | `20` / `200` | Shelf-life lookups per client |
| `SUBSTITUTE_PER_MINUTE` / `SUBSTITUTE_PER_DAY` | `10` / `100` | Ingredient swap requests per client |
| `MAX_INGREDIENTS_CHARS` | `300` | Maximum length of the ingredient input |
| `CLIENT_IP_HEADER` | empty | Header that carries the client IP behind a proxy |
| `HOST` | `127.0.0.1` | Use `0.0.0.0` to allow access from other devices on the local network |
| `PORT` | `5000` | Server port |

## API

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/health` | Health check |
| `GET` | `/api/options` | Supported countries, currencies and cooking situations |
| `POST` | `/api/recipes` | Generate five recipes |
| `POST` | `/api/shelf-life` | Estimate how long an ingredient keeps |
| `POST` | `/api/substitute` | Suggest substitutes for an ingredient |

Errors return `{"error": {"code": "...", "message": "..."}}` with a matching HTTP status.

## Deployment

The project is configured for Netlify in `netlify.toml`:

- `static/` is published as is (no build step).
- `/api/*` is served by `netlify/functions/api.mjs`, a JavaScript port of the Flask API.

Connect the repository in Netlify and set `GEMINI_API_KEY` under **Project configuration → Environment variables**. Every push to `main` deploys automatically.

## Testing

```bash
python -m pytest                              # Python server
node --test netlify/tests/server.test.mjs     # Netlify functions (Node.js 18+)
```

The tests mock all Gemini calls, so they need no API key and use no quota.

## Security

- The Gemini API key is used only on the server and is never sent to the browser.
- `.env` is excluded from version control.
- All input is validated on the server: ingredient length, and countries and situations against an allowlist.
- Requests are rate limited per client, and shelf-life and swap answers are cached to avoid repeated Gemini calls.
- Responses include a strict Content Security Policy and other security headers.
